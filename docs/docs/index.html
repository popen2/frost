Frost in one page

Frost is a menu-bar app for people whose AWS access comes from IAM Identity Center (formerly AWS SSO). Instead of running aws configure sso once and aws sso login forever after, you give Frost your access portal URL. From then on it:

  • keeps an SSO token alive, refreshing it as it expires — credential refresh;
  • writes a profile per account and permission set into ~/.aws/config, leaving everything else in that file untouched — profile names, the config file;
  • writes the SSO token into the cache the AWS CLI reads, so aws --profile … works without a separate login — files & locations;
  • scans every region for EKS clusters and keeps ~/.kube/config current — EKS discovery;
  • records what each run did, so a failure is something you can read rather than guess at — activity & logs.

There is no account to create, no server to talk to, and no telemetry. Frost is open source under Apache 2.0.
