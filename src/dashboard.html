Account Name Tips

In AWS SSO, you can control how account names appear in Frost by appending special annotations to your AWS account names:

  • #short-name — use this as the profile name prefix, e.g. Acme Production (#prod) → prod-admin
  • @region — set a preferred region for this account, e.g. Acme EU (#eu @eu-west-1)
