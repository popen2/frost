Account Name Tips

Frost reads annotations in your AWS account names to shorten profile names and set per-account regions.

#short-name → use as the profile prefix, e.g. Acme Prod (#prod) → prod-admin
@region → override the default region, e.g. Acme EU (#eu @eu-west-1)
